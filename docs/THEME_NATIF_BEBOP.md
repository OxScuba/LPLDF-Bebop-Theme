## Activation

1. Enregistrer le thème.
2. Le définir comme **Main theme**.
3. Dans le Layout, masquer le sélecteur de thème.
4. Vérifier le panier et une page sans CMS : ils doivent déjà reprendre la
   palette, même sans `custom.css`.
