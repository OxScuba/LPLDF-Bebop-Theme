# Validation visuelle

## Ordinateur

- aucun contenu ne déborde horizontalement ;
- les deux barres de navigation restent lisibles ;
- le héros occupe immédiatement l’écran sans cacher les boutons ;
- les textes restent lisibles sur l’image ;
- les cartes ont des espacements réguliers ;
- les widgets ne s’affichent pas sous forme de codes entre crochets ;
- les onze produits forment une grille et non une colonne interminable ;
- les boutons produit restent accessibles ;
- le footer présente les liens essentiels.

## Téléphone

- le menu mobile s’ouvre ;
- le panier reste accessible ;
- les boutons principaux prennent toute la largeur ;
- aucune image n’est coupée de manière gênante ;
- les doubles pages restent lisibles au zoom ;
- les grilles passent sur une colonne ;
- la fiche produit ne conserve aucun panneau `sticky`.

## Accessibilité

- navigation possible au clavier ;
- focus doré visible ;
- textes alternatifs présents sur les images informatives ;
- images décoratives avec `alt=""` ;
- animations désactivées si le système demande moins de mouvement ;
- contraste suffisant entre texte, fond bleu et fond crème.

## Conversion

- le Pack Découverte est visible avant le premier long défilement ;
- le prix et l’économie sont explicites ;
- un bouton d’achat ou de choix apparaît après chaque grande section ;
- la livraison, le paiement et le contact sont rassurants ;
- chaque fiche répond à : pour quel âge, quel sujet, que contient le livre,
  quel format, combien de pages, quel ISBN et quel prix.
- aucun bouton ni libellé commercial ne reste en anglais.
