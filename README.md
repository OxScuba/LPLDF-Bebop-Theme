# LPLDF Bebop Theme

Thème visuel et contenus CMS de la boutique be-BOP
**Les Petites Leçons de Frédéric**.

## CSS public

https://oxscuba.github.io/LPLDF-Bebop-Theme/custom.css

## Boutique

https://xn--lespetitesleonsdefrdric-89b1db.fr/

## Organisation

- `custom.css` : version actuellement utilisée par la boutique ;
- `versions/` : sauvegardes des versions précédentes ;
- `cms/` : HTML des pages CMS ;
- `docs/` : procédures be-BOP ;
- `CONTEXTE_PROJET.md` : mémoire destinée aux futures reprises du projet.

## Sécurité

Ce dépôt est public. Il ne doit contenir aucun mot de passe, accès SSH,
fichier `.env`, secret API ou donnée client.
